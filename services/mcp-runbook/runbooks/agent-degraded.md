# 조사 에이전트가 답하지 못함 (예산 소진, 도구 서버 연결 실패, 상한 도달)

Slack 봇이 조용하거나 "조사에 실패했습니다" 라고 답할 때.

## 증상

- Slack 에 `오늘 AI 사용 예산을 다 써서 조사하지 못했습니다`: 하루 예산($5) 소진.
- `조사에 실패했습니다 (agent 5xx 또는 연결 실패)`: 에이전트 파드 문제.
- 보고서 아래에 `한도 도달로 중단`: 도구 호출 15회, LLM 10회, 180초, 건당 $0.60 중 하나에 걸림.
- 보고서 근거가 빈약하고 특정 도구가 한 번도 불리지 않음: 그 MCP 서버에 연결하지 못함.

## 확인

- 예산: 지표 `agent_cost_usd_total` 의 오늘 합계, Grafana 의 에이전트 비용 대시보드.
- 도구 서버: `agent_mcp_unavailable_total` 이 늘었는지 (server 라벨이 연결 못 한 서버).
- 에이전트 로그: `MCP 서버 연결 실패`, `사건 기록 실패`.
- 알림이 한꺼번에 여러 개 와서 조사가 몰렸는지 (같은 원인의 알림 묶음).

## 원인 후보

- 알림 폭주로 조사가 연달아 돌아 예산을 씀 (공격 재현, 장애 주입 시험).
- MCP 서버 재배포 중이거나 토큰 불일치.
- 조사 범위가 넓어 상한에 걸림.

## 조치

- 예산은 자정(KST)에 초기화된다. 급하면 사람이 지표와 로그를 직접 본다. 차단과 격리는 에이전트와 무관하게 동작한다.
- 도구 서버 연결 실패는 그 서버 파드와 네트워크 정책을 본다.
- 에이전트가 없어도 알림은 Slack 에 온다. 조사 보고만 빠진다.
